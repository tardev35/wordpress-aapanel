# attack-lab — ซ้อมเจาะ WordPress ให้เห็นภาพ

จำลองลำดับที่บอทเดินเข้าเจาะเว็บ WordPress ที่ไม่มีการป้องกัน
เพื่อเห็นว่ากฎ hardening ของเราตัดขั้นไหนทิ้ง — ดู [docs/12](../../docs/12-attack-simulation.md)

## รัน (ต้องมี 2 เทอร์มินัล)

```bash
# เทอร์มินัล 1 — เปิดเป้า
python tools/attack-lab/target.py            # ไม่มีการป้องกัน
# หรือ
python tools/attack-lab/target.py --hardened # เปิดกฎชุดเดียวกับ configs/wp-hardening.conf

# เทอร์มินัล 2 — ยิง
python tools/attack-lab/attacker.py
```

ใช้ python มาตรฐานล้วน ไม่ต้อง pip install

## เครื่องมือทั้งหมด

| ไฟล์ | ทำอะไร | รันที่ไหน |
|---|---|---|
| `target.py` / `attacker.py` | จำลองลำดับการเจาะ WordPress ปลอม (ดู [docs/12](../../docs/12-attack-simulation.md)) | เครื่องตัวเอง (localhost) |
| `load-target.php` + `hammer.py` | สาธิตภาระ CPU จาก request ที่รัน PHP จริง | เครื่องตัวเอง (`php -S`) |
| `cpu-load-demo.sh` | สาธิตภาระ CPU ครบวงจร สร้าง endpoint ชั่วคราวแล้วยิงเอง | **VPS เปล่า** เท่านั้น |
| `serve-target.sh` | เปิดเป้าซ้อมโหลดสาธารณะให้ `hammer.py` ยิงข้ามเครื่อง | **VPS เปล่า** เท่านั้น |
| `testsite-guard.sh` | ล็อก IP เว็บทดสอบก่อนปลดเกราะ xmlrpc (ดู [docs/13](../../docs/13-safe-vuln-testing.md)) | เครื่องทดสอบ |
| `xmlrpc-load.sh` | ยิง xmlrpc multicall ใส่เว็บทดสอบของเราเองที่ล็อก IP แล้ว | เครื่องคุณ → เว็บทดสอบ |

## ปลอดภัยแค่ไหน

- เป้าจำลอง (`target.py`) เป็น **WordPress ปลอม** ไม่มีการรันโค้ดจริง
- เว็บเชลล์ที่ "อัปโหลด" เป็นไฟล์เปล่า ยกไปใช้กับที่อื่นไม่ได้
- ทุกอย่างอยู่ในแรม ปิดโปรแกรมแล้วหายหมด ไม่แตะดิสก์
- `attacker.py` ยิงได้แค่ `127.0.0.1` เท่านั้น
- ตัวยิงโหลดจริง (`cpu-load-demo.sh`, `serve-target.sh`) **ปฏิเสธที่จะรันถ้าเจอเว็บจริง**
  บนเครื่อง และ `hammer.py` ยิงเป้าไกลได้เฉพาะที่มี header `X-Load-Demo:1` ของเราเอง
- `xmlrpc-load.sh` ปฏิเสธ localhost, ตรวจว่าเป็น xmlrpc ของ WordPress จริงก่อน, ต้อง
  พิมพ์ชื่อโดเมนยืนยันเอง, และยัด **รหัสหลอกตัวเดียวซ้ำ ๆ ไม่ใช่ wordlist** —
  สาธิตภาระ CPU ได้แต่เดารหัสใครไม่ได้

เป็นเครื่องมือฝึกทีมงานให้เห็นภาพการโจมตีและพิสูจน์ว่าเกราะกันได้จริง
ไม่ใช่เครื่องมือโจมตีเว็บคนอื่น — ทุกตัวยิงได้เฉพาะเครื่อง/เว็บของเราเอง
