# attack-lab — ซ้อมเจาะ WordPress ให้เห็นภาพ

จำลองลำดับที่บอทเดินเข้าเจาะเว็บ WordPress ที่ไม่มีการป้องกัน
เพื่อเห็นว่ากฎ hardening ของเราตัดขั้นไหนทิ้ง — ดู [docs/12](../../docs/12-attack-simulation.md)

## รัน (ต้องมี 2 เทอร์มินัล)

```bash
# เทอร์มินัล 1 — เปิดเป้า
python tools/attack-lab/target.py            # ไม่มีการป้องกัน
# หรือ
python tools/attack-lab/target.py --hardened # เปิดกฎชุดเดียวกับ configs/wp-hardening.conf

# เทอร์มินัล 2 — ยิง
python tools/attack-lab/attacker.py
```

ใช้ python มาตรฐานล้วน ไม่ต้อง pip install

## ปลอดภัยแค่ไหน

- เป้าเป็น **WordPress ปลอม** ไม่มีการรันโค้ดจริง
- เว็บเชลล์ที่ "อัปโหลด" เป็นไฟล์เปล่า ยกไปใช้กับที่อื่นไม่ได้
- ทุกอย่างอยู่ในแรม ปิดโปรแกรมแล้วหายหมด ไม่แตะดิสก์
- `attacker.py` ยิงได้แค่ `127.0.0.1` เท่านั้น

เป็นเครื่องมือฝึกทีมงานให้เห็นภาพการโจมตี ไม่ใช่เครื่องมือโจมตีเว็บจริง
