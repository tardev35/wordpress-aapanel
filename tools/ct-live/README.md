# ct-live — ดูสตรีม Certificate Transparency สด ๆ ผ่านหน้าเว็บ

หน้านี้คือ [scripts/watch-ct.sh](../../scripts/watch-ct.sh) เวอร์ชันหน้าเว็บ
ทำไว้ให้เห็นภาพว่า **บอทหาโดเมนที่เพิ่งจดใหม่เจอได้จากที่ไหน** — ดู [docs/11-security.md](../../docs/11-security.md)

## รัน

```bash
python tools/ct-live/server.py      # เปิด http://localhost:8765
```

ใช้แค่ python มาตรฐาน ไม่ต้อง pip install อะไร

## เมนู

| เมนู | ทำอะไร |
|---|---|
| สตรีมสด | ดึงใบรับรองล่าสุดจากทุก CT log แยกแท็บตาม log |
| ล็อกที่ใช้ได้ | รายชื่อ log ที่ยังรับ cert อยู่ตอนนี้ |
| เฉพาะโดเมนของเรา | กรองเฉพาะโดเมนใน `/www/wwwroot` (ใช้ได้เมื่อรันบนเซิร์ฟเวอร์) |
| คัดกรองเว็บพนัน | ส่งชื่อโดเมนให้ AI ช่วยดูว่าตัวไหนน่าจะเป็นเว็บพนัน |

## เปิดใช้ตัวคัดกรอง AI

```bash
cp tools/ct-live/.env.example tools/ct-live/.env
# แก้ .env ใส่คีย์จาก https://openrouter.ai/keys
```

รัน server ใหม่ แล้วเข้าเมนู **คัดกรองเว็บพนัน**

ส่งไปแค่ **ชื่อโดเมน** ไม่ได้เปิดเว็บ ไม่ได้ส่งอย่างอื่น
รุ่นเริ่มต้น `google/gemini-3.1-flash-lite` — 45 โดเมนใช้ราว 850 token เข้า

⚠️ โมเดลดูจากชื่ออย่างเดียว **ผิดได้ทั้งสองทาง** เว็บทั่วไปที่มีตัวเลขอาจโดนทำเครื่องหมาย
และเว็บพนันที่ตั้งชื่อธรรมดาจะรอด ใช้จัดลำดับว่าควรดูตัวไหนก่อน ไม่ใช่คำตัดสิน
