## ปรับตัวคัดกรองใหม่เมื่อมีข้อมูลเพิ่ม

```bash
python tools/ct-live/tune.py --emit
```

แบ่ง 70% ไว้เรียน 30% ไว้ทดสอบ ตัวเลขที่รายงานมาจากส่วนที่ไม่เคยเห็น
เพื่อไม่ให้ได้เลขสวยเพราะจำคำตอบ แล้วค่อยเรียนใหม่จากข้อมูลทั้งหมด

ได้ไฟล์ออกมา 2 ตัว:

| ไฟล์ | คำ | ขึ้น git |
|---|---|---|
| `vocab.json` | 249 | ❌ มีชื่อแบรนด์ของเรา (`bluekong`, `pigauto`, `ambkingbet`) |
| `vocab-generic.json` | 156 | ✅ มีแต่คำกลาง ๆ ของวงการ |

หน้าเว็บใช้ `vocab.json` ก่อนถ้ามี ไม่มีก็ถอยไปใช้ `vocab-generic.json`
ตัดชื่อแบรนด์ออกแล้วเสียความแม่นแค่ 0.5% (88.3% → 87.8%) คุ้มกว่าเอาไปเปิดเผย
